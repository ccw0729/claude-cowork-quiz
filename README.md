## 中文

六個工作情境，練習判斷每項任務該交給 Claude 的哪一種用法：**Chat**、**Cowork** 或 **Code**。題目與解說參考 Anthropic Academy 課程〈Introduction to Claude Cowork〉的「您會選擇哪一個？」練習。

### 兩種作答模式

| 模式 | 檔案 | 適合情境 |
| --- | --- | --- |
| [逐題解說](https://ccw0729.github.io/claude-cowork-quiz/quiz-instant.html) | `quiz-instant.html` | 每答一題就顯示對錯與解說，跟官網練習相同，適合自學 |
| [最後公布答案](https://ccw0729.github.io/claude-cowork-quiz/quiz-final.html) | `quiz-final.html` | 六題答完再一次公布，可回上一題修改，適合課堂小測驗 |

### 題目涵蓋

- 讀取本機 PDF、比較後輸出試算表
- 在儲存庫中重構模組並執行測試
- 腦力激盪產品標語
- 從桌面試算表整理單頁簡報並存到指定資料夾
- 從 Slack 頻道歸納客戶回饋主題
- 追蹤 React 元件錯誤並推送修復

### 要記住的模式

> **Chat** 用於思考，**Cowork** 用於委派，**Code** 用於軟體開發。
> 如果有疑問，就問問這項任務是否涉及您的檔案或工具，並以一個實際的交付成果結束。如果是，就選 Cowork。

### 說明

- 每個測驗都是單一 HTML 檔，不需要後端，下載後用瀏覽器直接開啟也能作答。
- 支援手機寬度與深色模式，可直接投影上課或讓學員用手機作答。

## English

Six work scenarios to practice choosing the right way to use Claude for each task: **Chat**, **Cowork**, or **Code**. Questions and explanations are based on the "Which would you choose?" exercise in the Anthropic Academy course *Introduction to Claude Cowork*.

### Two quiz modes

| Mode | File | Best for |
| --- | --- | --- |
| [Instant feedback](https://ccw0729.github.io/claude-cowork-quiz/quiz-instant.html) | `quiz-instant.html` | Shows right/wrong and the explanation after each answer, like the official exercise. Good for self-study. |
| [Answers at the end](https://ccw0729.github.io/claude-cowork-quiz/quiz-final.html) | `quiz-final.html` | Reveals all answers after the sixth question; you can go back and change answers. Good for in-class quizzes. |

### The pattern to remember

> **Chat** is for thinking, **Cowork** is for delegating, **Code** is for building software.
> When in doubt, ask whether the task touches your files or tools and ends in a real deliverable. If it does, choose Cowork.

### Notes

- Each quiz is a single HTML file with no backend. Download it and open it in a browser to use it offline.
- Works at phone width and in dark mode.

> The quiz interface is in Traditional Chinese.
